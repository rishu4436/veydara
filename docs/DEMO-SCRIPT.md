# Demo script (current build, ~3 min)

1. **Overview, disconnected** — "Start from what you own." Topbar shows CMC status; the source-health drawer and `/proof` show the key-access probe (402/1004 plan expired) and that keyless endpoints are serving.
2. **Watch the Aave V4 Equities Hub contract** (`/?watch=0xa4d5947Eb727A052bae69C593FfC84247EC9864E`). Real block-pinned balances of USDC and eight Coinbase tokenized equities; Capital Constellation links each holding to its underlying and to the Aave V4 reserve with its collateral factor (table view for accessibility).
3. **Open NVDAc → Collateral Passport.** Price triad (CMC token quote vs CMC aggregate [unavailable: plan expired] vs Aave oracle) with the disagreement flag; live reserve facts (CF 70%, add cap, bonus 5.5%); real DEX candles with EMA20/50 and S/R zones, outlier wick disclosed; multi-horizon research (1h/4h/1d) with consensus and sources; issuer graph (unavailable with exact reason).
4. **Positions** — pick a public recent borrower. Spoke health factor with "VEYDARA recomputation matches exactly ✓", liquidation prices per collateral, drawdown to liquidation, APR, headroom; Risk Clock shows what a Monday gap does to HF; Parallel Futures table; full reserve table.
5. **Strategies (Solver Arena)** — choose a low-leverage borrower: Fortress / Gap-proof / Buffer-35 verified with exact HF; Aggressive rejected by the verifier on the HF ≥ 1.25 policy; expand the checks.
6. **Fork Lab** (`pnpm fork` running) — violet FORK banner (chain 31337, Base block N). Fund an anvil test account with 1 NVDAc by impersonating a real holder on the fork; preset 1 → Prepare: stages tick through validate → fork guard → fresh state → typed route → verifier → simulation; preview shows four plain-language steps, exact approval, HF ∞ → 3.03. Tick the review box → Sign & send on fork → four FORK receipts, before/after table, 10/10 reconciliation (VEYDARA HF = Spoke HF). Run preset 2 (partial repay) and 3 (withdraw). Then the policy test: verifier blocks a borrow the protocol would allow (HF 1.12 < 1.25) — nothing signed, refusal recorded.
7. **Guardian** — watch a near-liquidation public borrower: radar is critical (HF 1.03, 2.7% from liquidation, gap HF 0.93); Evaluate now → three monitor-only alerts, bell badge; emergency center lists a real unlimited USDC allowance discovered from Approval logs → prepare revoke → fork simulation shows allowance → 0 in a reverted snapshot; unsigned tx for the user's own wallet.
8. **Account (SIWE)** — connect, *Sign in with Ethereum*, link a second wallet; cookies are HttpOnly/SameSite=Strict; "Mainnet signing: unavailable".
9. **Fork Lab with my wallet** — signer "My wallet", Switch / add VEYDARA fork (31337), fund, preset 1 → Sign with my wallet on fork → four FORK receipts tagged "signed by user wallet", reconciliation 10/10.
10. **Intent Engine** (Strategies) — "Borrow max USDC against NVDAc but survive a 40% drop" → parsed constraints with spans, target HF 1.6667, constrained arena picks the verified plan; "borrow 5000000 USDC" → out-of-range error, not clamped; "buy a boat" → listed as unrecognised.
11. **Kamino (Solana)** — verified xStocks market reserves (read-only) and a public sample borrower's distance to liquidation.
12. **Proof Center** — fork execution records (executed, blocked, revert drill with decoded `HealthFactorBelowThreshold()`), credit ledger rows from steps 2–5 (keyless fallback tagged), capability matrix, recorded key probe.

With an active CMC key the same build lights up RWA aggregate prices, the issuer graph (NVDAX, NVDAon, … vs NVDAc) and CEX OHLCV — no code change.
